# Changelog

## Unreleased

- 新增 `AGENT_SETUP.md`，为 Codex、Claude 及其他本地 coding agent 提供可发现的安装、
  启动、验活和安全停止条件；README 增加可直接转发给 Agent 的入口提示。
- 新增 Comment、逐条 AgentReview、整篇审校进度、跨页批量送审、批准修复池、
  RepairBatch/PagePatch、逐页裁定和最终候选原子安装；跨 PDF 经验候选库仍未实现。
- 质量检查默认隐藏无需人工处理的技术提示，只把高置信待办送入主队列；旧 QA 记录与
  当前 Comment/修复状态分层展示。
- 扫描页在擦除原文前先做排版可容纳性检查；clean 模式任一段无法安全放置时整页回退
  overlay，保留源图，并把渲染模式、原因和 fallback 写入正式 page-plan 与 QA。
- AgentReview 改为按 `comment_id` 独立返回；缺失、重复或串线时整批失败关闭，避免把
  同一模型判断错误复制给多个 Comment。
- 接受修复候选时对中文 PDF、双语 PDF、QA 和逐页计划执行整组事务安装；新增任务级
  变更锁，翻译、修复、接受与删除之间互斥，失败时回滚旧输出。
- Codex 翻译与审阅使用空白临时工作区并禁用执行、应用、浏览器和多 Agent 工具；
  Claude 文本翻译禁用工具，截图审阅只开放两张临时复制图片。界面与文档不再声称
  “原文不上传”，明确说明模型会接收任务所需的文字或页面截图。
- 无私有回归材料的公开分发形态测试为 131 passed、19 skipped；私有回归材料通过环境
  变量从仓库外显式加载，不进入公开仓库。

## v0.1.1 — 2026-08-12

- canonical 受管 Python 回归 59/59 通过；翻译与 OCR doctor 均通过。

## v0.1.0 — 2026-08-11

首个公开版本（macOS）。

- 文本型与扫描版英文 PDF：页面级自动路由（text / ocr），扫描页走独立受管 PaddleOCR
  运行时（英文 PP-OCRv5，按需安装、离线复用）。
- 产出中文 PDF、同页左右对照双语 PDF、可搜索原文 PDF、页面级 OCR JSON。
- 扫描页翻译底稿与可搜索交付物分离：文字页白底重排、图版页保图遮字，消除中文与
  扫描像素叠印。
- 翻译经本机 Codex / Claude CLI 登录态；Claude 调用带配置隔离与纯翻译系统提示；
  模型拒答段保留原文并产生页面级告警，不静默、不挂起。
- 确定性 QA（qa-alpha）按页面路由分档：扫描页以覆盖率与告警为主，文本页保留
  渲染类判据；新增模型元回复泄漏检测。
- 运行时依赖全部锁定（uv 受管 Python 3.12、pdf2zh 固定 commit、模型资产哈希清单）；
  doctor 门禁覆盖翻译引擎完整导入链。
- 已知边界：多栏页（如索引）的 OCR 阅读顺序可能跨栏交错；图版为主页面的方向
  分类偶发误判；拉丁术语密集页（索引/图注）可能保留英文。均会被 QA 标记。
