# Provenance

## 来源

本目录是一个重新实现的公开参考包，架构来自一个长期运行的本地科研信息链实践，核心经验包括：

- 每个来源先落 raw artifact 与 manifest receipt，再汇总 health；
- 把上游访问时间与本地产物生成时间分开；
- 增量、去重、时效门和筛选在渲染之前完成；
- 日报、网站和内容包共同读取同一份 `daily_items.jsonl`；
- 账号型来源、个人画像和网络推送默认关闭。

公开包不是内部工作区的镜像，也不包含内部 Git 历史、运行数据、配置、任务卡、账号状态或绝对路径。代码为本目录重新编写，示例数据为虚构内容。

## 版本血统

公开版本使用独立的语义版本号。内部实现可能继续演化，公开版本不宣称与任何未发布工作树逐文件相同。

## 内容来源

离线 fixture 中的标题、作者、期刊、机构、摘要、URL 和标识符均为合成值。在线模式只返回上游提供的元数据与链接；使用者负责遵守对应 API、Feed 和网站条款。
