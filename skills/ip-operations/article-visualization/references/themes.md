# 配色主题库(不写死配色)

**为什么有这页**:之前把暖陶土(Claude 色系)写死进模板 → 不管什么文章都长一个样,这正是「default 千篇一律 / AI slop」。配色应**按内容领域、品牌、或用户意图**选,不该锁死。

## 切换方式
所有色走 CSS 变量;在卡片/页面根元素设 `data-theme` 即可整套换肤,**不动任何结构**:
```html
<html lang="zh-CN" data-theme="cool-clinical">
```
主题定义在 `templates/xhs-card.css` 顶部(长图模板同理可加)。

> 这是「没思路时翻的弹药」,不是清单。用户给了品牌色/参考,就从那里长,别套库。
> **温度对冲**:模型天然偏安静极简——一批别全落 `warm-popsci`/安静款;数据/风险/媒体类**主动选大胆款**(swiss/safety/neo/midnight)。
> `neo-brutalism` 不止换色,还带专属**粗黑描边 + 5px 硬投影 + Mono 标签**样式(见 css 末尾),是"风格"而非纯"配色"的范例——后续可照此扩更多风格层。

## 选主题的规则(优先级)
1. **用户明确意图/品牌优先**:用户说了风格(「冷一点」「像××」)或给了品牌色 → 据此**自定义一套** `data-theme="brand-xxx"`(直接在 css 里加一组变量)。
2. **按内容领域兜底**:医学→cool-clinical;数据/技术→swiss-bold;严肃观点→ink-editorial;其余/生活→warm-popsci。
3. **不要无脑默认暖色**:同一批若全落 warm-popsci,就是在重复 AI slop;领域不同就换。
4. **一篇一主题**:同一套图文用一个主题,别混。

## 人类介入(intent 输入)
开工前可一次性问(用户不答就 AI 按领域决定,并说明可换):
```
这篇想要什么气质?(可不答,我按内容领域选)
· 平台:小红书 / 公众号 / 长图…   · 受众:大众科普 / 同行…
· 风格:暖科普 / 冷临床 / 数据蓝 / 严肃墨刊 / 跟随我的品牌色(给色值)
```
AI 据内容自定义,把选定主题写进该 case 的 brief.md。

## 加新主题
在 `xhs-card.css` 复制一组 `[data-theme="x"]{ --clay…--amber… }`,只改色值。建议至少覆盖:强调三色(clay/deep/soft)、底三色(cream/cream-2/paper)、文字与线(ink/ink-2/muted/line)。
