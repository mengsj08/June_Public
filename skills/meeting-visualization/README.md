# Meeting Visualization Skills

Skills for turning meeting notes, transcripts, and Feishu/Lark meeting records into local analysis cases and customer-safe HTML summaries.

## Included Skills

- `feishu-meeting-workflow/`  
  Feishu/Lark meeting workflow for resolving AI notes or transcript docs, creating local meeting cases, guiding CRM handoff decisions, and rendering meeting analysis into standalone HTML.

## Public Safety

This category must not include local Lark CLI profiles, app credentials, user tokens, fetched customer transcripts, generated runtime workspaces, or private meeting outputs.
