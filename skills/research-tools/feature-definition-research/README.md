# 以功能定义为主线的竞品研究

围绕功能要解决的用户问题开展研究，把产品承诺、实现假说和实际价值分开，并优先补能改变判断的证据。

## 适用场景

| 你想做什么 | 主要输出 |
| --- | --- |
| 新功能或卖点拆解 | 用户任务、可证实的功能程度、实现假说与价值判断 |
| 新旧版本比较 | 区分新任务、能力增强、集成变化与重新命名 |
| 我方功能定义（须明确要求） | 能力要求、输入输出边界、候选路线与验收标准 |

## 使用方式

将本目录交给具备文件阅读、网页检索和文献核验能力的 AI Agent，要求它完整阅读 [SKILL.md](SKILL.md)，再按其中链接读取相关模板和参考材料。先给出研究对象、地区、时间截止点、读者及用途；已有资料一并提供。

示例提示：

> 请分析某品牌指定版本的三项重点功能。读者是研发负责人，只做竞品分析。先给功能全貌，再核实前代变化、实现候选和用户价值；没有证据的地方保留条件性判断。

产品族谱可作为前代基线，但不要求先执行另一套 Skill。 两个方法包可独立使用，没有指定插件、专用看板、私有服务或 API 的硬依赖。Mermaid 仅用于可选图表展示，不支持时可用文字或表格表达。
