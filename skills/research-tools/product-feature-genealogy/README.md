# 产品与功能族谱调研

把产品关系与功能演进放在一起研究，解释产品之间是什么关系、能力何时出现，以及升级到底改变了什么。

## 适用场景

| 你想做什么 | 主要输出 |
| --- | --- |
| 认清品牌产品线 | 有来源的产品分支与关系图 |
| 追溯发布和供货 | 区分发布、监管许可、供货、地区上市的事件表 |
| 判断功能演进 | 前代基线、本代能力与增量的证据矩阵 |

## 使用方式

将本目录交给具备文件阅读、网页检索和文献核验能力的 AI Agent，要求它完整阅读 [SKILL.md](SKILL.md)，再按其中链接读取相关模板和参考材料。先给出研究对象、地区、时间截止点、读者及用途；已有资料一并提供。

示例提示：

> 请梳理某品牌截至指定日期在指定地区的主要产品家族。分清后继、并行用途与地区版本，输出族谱、关键发布事件和功能变化；不要将获证日当作首销日。

如需进一步拆解单项功能，可另行做功能研究，但本包不自动调用其他 Skill。 两个方法包可独立使用，没有指定插件、专用看板、私有服务或 API 的硬依赖。Mermaid 仅用于可选图表展示，不支持时可用文字或表格表达。
