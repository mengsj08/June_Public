# openclaw-beginner-guide

Status: archived reference.

Introductory guide for explaining the OpenClaw configuration model to beginners.

## When To Use

- A user is new to OpenClaw and needs a short conceptual explanation.
- A user wants either a quick overview or a guided deeper walkthrough.
- This can be used before writing actual configuration files.

## Quick Start For AI

```text
Use openclaw-beginner-guide in Quick mode and explain the OpenClaw workspace files in plain language.
```

```text
Use openclaw-beginner-guide in Deep mode. Ask one question at a time and teach the configuration model step by step.
```

## Covers

- `SOUL.md`: agent principles and boundaries.
- `AGENTS.md`: workflows and permissions.
- `MEMORY.md`: long-term lessons and preferences.
- `HEARTBEAT.md`: proactive routines and checks.

## Safety

- This skill explains concepts; it should not install or modify a live workspace by itself.
- Do not ask the user to paste secrets, tokens, or private credentials.
