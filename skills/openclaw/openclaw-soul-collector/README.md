# openclaw-soul-collector

Status: archived reference.

Guided interview for drafting `SOUL.md`, the agent's principles, boundaries, and communication style.

## When To Use

- The user wants to define agent behavior and absolute red lines.
- The user already has other OpenClaw files and only wants to revise `SOUL.md`.
- The AI should turn user preferences into direct, enforceable instructions.

## Quick Start For AI

```text
Use openclaw-soul-collector. Ask whether we are using Quick or Deep mode, then draft SOUL.md for review.
```

## Inputs

- Core work principles.
- Absolute boundaries.
- Communication style and disliked patterns.

## Output

- Reviewable `SOUL.md` Markdown draft.

## Safety

- Ask one question at a time.
- Make boundaries explicit.
- Do not save into a live workspace until the user approves.
