# OpenClaw Skills

Status: archived reference. These skills are kept in the public repo for historical and learning purposes. They are not the recommended path for new workflows unless explicitly promoted again.

## Skills

| Skill | Purpose |
| --- | --- |
| `openclaw-onboarding-wizard/` | One conversation that generates `USER.md`, `IDENTITY.md`, `SOUL.md`, `AGENTS.md`, and `HEARTBEAT.md` drafts |
| `openclaw-beginner-guide/` | Explains the OpenClaw configuration model in Quick or Deep mode |
| `openclaw-soul-collector/` | Generates a `SOUL.md` draft for agent principles, boundaries, and tone |
| `openclaw-agents-builder/` | Generates an `AGENTS.md` draft for workflows and permissions |
| `openclaw-heartbeat-builder/` | Generates a `HEARTBEAT.md` draft for proactive checks and routines |
| `openclaw-user-builder/` | Generates a `USER.md` draft for user profile and preferences |
| `openclaw-identity-builder/` | Generates an `IDENTITY.md` draft for agent name, persona, display style, and avatar |

## How To Use

Place the selected skill directory into an OpenClaw-compatible skills directory, then ask the AI to use that skill and follow `SKILL.md`.

Example:

```text
Use openclaw-onboarding-wizard to help me draft the five OpenClaw workspace configuration files.
```

## Safety

- Review generated Markdown before placing it in a real agent workspace.
- Do not include passwords, API keys, private customer data, or account tokens in generated configuration files.
- Treat these as archived examples unless the project owner explicitly reactivates them.
