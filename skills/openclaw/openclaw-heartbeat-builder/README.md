# openclaw-heartbeat-builder

Status: archived reference.

Guided interview for drafting `HEARTBEAT.md`, the proactive check and routine list for an OpenClaw agent.

## When To Use

- The user wants recurring checks, reminders, or periodic work instructions.
- The user needs a daily routine or repeated inspection checklist.
- The user only wants to revise `HEARTBEAT.md`.

## Quick Start For AI

```text
Use openclaw-heartbeat-builder. Ask one question at a time and draft HEARTBEAT.md with recurring checks and daily routines.
```

## Inputs

- Channels or sources to monitor.
- Reminder or schedule needs.
- Daily routines.
- Security constraints.

## Output

- Reviewable `HEARTBEAT.md` Markdown draft.

## Safety

- Do not put passwords, API keys, customer private data, or raw account tokens in heartbeat instructions.
- Proactive actions that send messages, delete data, or change external systems should require approval.
