作者文献地图 Author Literature Map — one researcher, every claim traceable

给一位研究者做一张文献地图,难的从来不是画图,是"这些论文到底是不是同一个人的"。 这套工具把身份消歧交给人拍板,把每一个数字都做成可机器核验的账本——换个人,同一套流程。

为什么这么设计

01 / 身份交给人

数据库会把一个人拆成好几个作者 ID,也会混进同名的陌生人。所以"哪些 ID 是同一个人"由人确认,一个门禁脚本在没确认前拒绝出"已确认"的图。

02 / 一本账

每个计数只在 AUTHOR_MAP.json 里算一次,网页只是它的投影——指标、年份直方图、论文表永远对得上,不会打架。

03 / 可复查的溯源

账本给每个输入文件记一个 SHA256。底层证据一变,重新渲染时页面自动打上 STALE 过期标记。

04 / 多源可插拔

PubMed、Semantic Scholar 作为补充腿接入,按 DOI/PMID 跨源去重;身份不明的行(如纯姓名搜索)自动路由到人工复核,绝不上主线。

两遍法 + 一道人工门

身份遍

收集候选作者 ID,并为每个 ID 摆出可观察证据:与已知 DOI 种子的重合度(最强信号)、机构、主题、同名他域信号。

人工修正门(必经)

人确认哪些 ID 是同一个人,产出 profile.yaml。门禁脚本用代码强制:没确认就不许出"已确认"的图。

全量遍

按确认口径拉全量,分成三桶:主线(已确认)/ 待复核 / 排除(同名)。你自带这三桶,本工具负责核验与渲染。

账本 + 渲染

生成单一事实源 AUTHOR_MAP.json,再从它渲染一张静态 HTML 地图——每条带来源标签,数字自洽,证据变了会标过期。

30 秒试跑(离线,无需联网)

# 从内置示例构建账本,再渲染 HTML 地图
python3 scripts/build_author_map_verdict.py --run-dir example --author "Jane Doe"
python3 scripts/render_author_map.py       --run-dir example --author "Jane Doe"
open example/index.html

这是开源自包含的那一块:账本 + 渲染器 + 补充腿(PubMed / Semantic Scholar)+ 身份门。 你自带已确认的作者 ID 列表和一份作品 CSV(如 OpenAlex 导出);产出这三桶的身份消歧引擎不在本包内。

包里有什么

  • build_author_map_verdict.py — 单一事实源账本:所有计数只此一处 + 分源明细 + 输入 SHA256
  • render_author_map.py — 只从账本渲染静态 HTML;证据漂移显 STALE
  • pubmed_author_supplement.py — PubMed 年份补充腿(公开 E-utilities,纯标准库)
  • s2_author_supplement.py — Semantic Scholar 补充腿(锚定→主线,姓名搜→复核)
  • assert_profile_confirmed.py — 身份门前置断言:未确认则非零退出
  • references/method.md — 完整方法:两遍法、人工门、exclude_keywords 的坑、显示规则
